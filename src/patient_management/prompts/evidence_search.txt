- Use these queries (or very close equivalents). Never add the patient's name, dates, record ids or lab values to a query:
$queries
- Prefer, in order: official guidelines, government health agencies, national/international professional societies,
  consensus statements (Tier 1); systematic or authoritative reviews in peer-reviewed journals (Tier 2);
  peer-reviewed original research (Tier 3); reliable medical institution education pages (Tier 4).
- Preferred source types for this request: $preferred
- Known authoritative bodies (hints, not a closed list): $hints
- Never use: forums, social media, Q&A sites, encyclopedias, commercial health sites, SEO content ($disallowed).
- Recency: $recency ("latest" = the newest guideline or consensus; check publication dates).
- At most $max_sources sources. Fewer high-quality sources are better than many.

IF YOU CANNOT SEARCH
If you have no web access or the search fails, return {"module": "evidence_bundle", "request_id": "$request_id", "search_status": "unavailable"}.
Never answer from memory or pretend you searched. If you searched but found nothing reliable, use "no_results".

WHAT TO REPORT
- Exactly one JSON object; no Markdown, no prose, no overall answer or summary.
- Copy title, organization/authors, URL and publication date exactly as shown by the source.
- "relevant_claims": 1-5 short claims, each ONE medical point as the source states it. Keep its hedging (may, often, suggests).
  No claim without its source. Do not mention this patient in claims.
- "applicability": which population/setting the source covers. "limitations": what it does not cover.
- If your search tool returned a result list, copy it into "search_metadata" (query, url, title).
- "verification": "page_accessed" ONLY if you opened the page/document and found each claim in it.
  If you only saw a search snippet or summary, or the page was blocked (403/paywall), use "snippet_only":
  such sources are recorded for discovery only and are never used as medical evidence.
